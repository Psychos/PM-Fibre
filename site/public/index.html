PM Fibre

Localiser rapidement les Points de Mutualisation sur le terrain

⬇ Télécharger l'application (Android)
Fichier .apk · Version 1.01

Ce que fait l'application

  • Recherche des PM par code ou par commune, avec base embarquée hors-ligne
  • PM à proximité, triés par distance
  • Carte avec position exacte (verte) ou approximative (rouge) des PM
  • Détection du PM dont la zone officielle ARCEP couvre votre position actuelle
  • Enregistrement et partage des positions relevées sur le terrain

Installation

L'application n'est pas publiée sur le Play Store : après téléchargement, ouvrez le fichier .apk depuis votre téléphone Android et autorisez l'installation depuis « sources inconnues » si demandé. Un compte est nécessaire pour synchroniser les positions ; la création demande un code d'équipe fourni séparément.
